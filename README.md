# 🏢 Attendance Management System – Hindustan Copper Limited

## 📌 Project Overview

The **Attendance Management System for Hindustan Copper Limited (HCL)** is a web-based application designed to simplify and streamline employee attendance and workforce management.

The system provides separate interfaces for administrators and employees, allowing efficient management of employee records, attendance tracking, leave applications, shift schedules, and employee reports.

The primary objective is to reduce manual administrative work, improve attendance monitoring, and provide a centralized platform for employee management.

## 🎯 Project Objectives

- Automate employee attendance management.
- Maintain organized employee records.
- Provide separate access for administrators and employees.
- Simplify leave application and management.
- Manage employee shifts and working hours.
- Generate employee attendance and performance reports.
- Improve transparency and efficiency in workforce management.

## ✨ Key Features

### 1. Admin Module

Administrators can manage employee information and monitor workforce activities.

- Admin authentication and login.
- Add and delete employee records.
- Search employees using Employee ID.
- View employee personal information.
- Monitor employee attendance records.
- View and manage leave requests.
- Manage employee shift information.
- Update employee employment status.
- Generate detailed employee reports.

### 2. Employee Module

Employees can access their personal information and attendance-related services.

- Employee login authentication.
- Personalized employee dashboard.
- View personal employee details.
- Check monthly attendance percentage.
- View attendance history.
- Apply for different types of leave.
- Check leave request status.
- View assigned shift information.

### 3. Attendance Management

The system maintains employee attendance information, including:

- Employee ID and attendance date.
- Time-in and time-out records.
- Attendance status (Present, Absent, Half Day).
- Total working hours.
- Work location classification (Surface/Underground).

### 4. Leave Management

- Submit leave applications.
- Specify leave type and duration.
- Provide reasons for leave.
- Track leave application status.
- Admin-side leave request monitoring.

### 5. Shift Management

- Maintain employee shift information.
- View assigned shift timings.
- Differentiate regular and other shift types.
- Track night-shift information.

### 6. Employee Status Management

Administrators can update employee employment status for different situations:

- Medical Unfit
- Resignation
- Retirement
- Death Case

The system also supports uploading relevant supporting documents for applicable status updates.

### 7. Employee Report Generation

Generate detailed employee reports containing:

- Employee personal information.
- Employment status.
- Attendance summary.
- Present and absent days.
- Underground working records.
- Shift summary.
- Leave request summary.
- Supporting document information, where applicable.
